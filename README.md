# חותם – אפליקציית מילוי וחתימה על מסמכים

גרסה עצמאית (PWA) של האפליקציה. כל הקבצים בתיקייה הזו הם אתר סטטי מלא.

## העלאה לאוויר
מעלים את כל התיקייה לכל אחסון סטטי עם HTTPS, למשל GitHub Pages, Netlify או Cloudflare Pages.
אחרי הפתיחה בטלפון: בכרום "הוספה למסך הבית", בספארי שיתוף ← "הוספה למסך הבית".

## מה יש בפנים
- `index.html` – האפליקציה כולה
- `pdf.worker.min.js` – רכיב קריאת PDF (חייב לשבת ליד index.html)
- `manifest.webmanifest`, `sw.js`, אייקונים – התקנה כאפליקציה ועבודה גם בלי רשת אחרי הפתיחה הראשונה

## פרטיות
המסמכים לא נשלחים לשום שרת. הזיהוי, המילוי ויצירת ה-PDF קורים בדפדפן של המשתמש.
